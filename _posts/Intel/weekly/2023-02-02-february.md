### how to share

目前，已有的结果是：**group的sharing关系**，例如第1，3，8个group可以共享（完全不考虑group所在的层级以及所对应的tree）

需要搞清楚的是：**用于share的data sample，怎么存，如何使用**。有以下几种方案：

1. lazy mode: 同一个set中的group第一次被使用到时，才去进行gather
2. eager mode: 对所有的set都预先进行gather

这两种方案，都有些问题。lazy mode可能会出现多线程对同一块内存的写入，导致性能下降；eager mode即使在分享率达到10的情况下，仍然会消耗大量的gather，原因在于：**在第二层的16个group中，只有一个group会被真正使用到，如果直接对这第二层的所有group都预先进行gather，那么将会出现大量的浪费**

所以，我们应当**尽可能的对确切会被使用到的group进行share**，之前无论是lazy mode还是eager mode，思考的前提都是：**对所有group进行share**。而现在，我们应当修改这一假设，即：**尽可能的对被使用到的group进行share**。

因此，对当前的目标实现进行限制：
> 1）**对所有tree第一层的group进行share** 


### where to save

从尽可能的提升sharing rate的角度来思考，那么应当尽可能的保证：**能share的group在同一个数据结构中**，然而从之前的sharing打印结果来看，share的分布非常不平衡，例如第一个set可能包含了200多，而有的可能只有3，4个，**这很有可能会不利于多线程的负载均衡**。因此，我假设：

> 2）**保证每个set都包含相同数目的group** 

目前，准备直接按照排列顺序进行划分，考虑到训练过程中，**loss的下降具有一定连续性**，连续的boost tree会包含相类似的feature

python侧的模型转化（`convert_tree_agg`）

```python
import json
from collections import deque

class TreeAgg:
    def __init__(self, roots, reg, idx):
        self.roots = roots
        self.reg = [list(x) for x in reg]
        self.idx = idx

def binary_tree_to_dict(root):
    
    tree = {'weight': [], 'index': []}
    queue = deque([root])

    while queue:
        node = queue.popleft()
        if 'leaf' not in node.keys():
            tree['weight'].append(node['split_condition'])
            tree['index'].append( int(node['split'][1:]))

            for child in node['children']:
                queue.append(child)

        else:
            tree['weight'].append(node['leaf'])
            tree['index'].append(0)
        
    return tree


def tree_agg_to_dict(tree_agg):
    
    tree_agg_dict = {
        'reg': list(tree_agg.reg),
        'idx': tree_agg.idx,
        'trees': []}

    for root in tree_agg.roots:
        tree_agg_dict['trees'].append(binary_tree_to_dict(root))
    
    return tree_agg_dict

def save_tree_agg(tree_dict, filename):
    with open(filename, 'w') as f:
        f.write(json.dumps(tree_dict))

def convert_tree_agg(groups_root, feat_set, gid_set):

    tree_agg = TreeAgg(groups_root, feat_set, gid_set)
    tree_agg_dict = tree_agg_to_dict(tree_agg)
    save_tree_agg(tree_agg_dict, 'test.json')

```

### mixed group prediction

目前，为了提升分享率，根据$C^{NodeNum}_{VectNum}$，需要降低共享的节点数目，因此，一次计算的层数从原来的4层变成了目前的3层，然而，如何实现8层tree的预测？

采取的方案是mixed group prediction，即在最后一层使用if/else，而非直接向量化，向量化在最后一层的计算浪费最大。因此，这里存在trade off，需要进行良好的平衡

<img src="/img/20230222201149.png" width = "500" alt="图片名称" />

目前实现如下：

```cpp
inline uint8_t next(const __m512& r, const float* data) {
    nodeStat s;
    __m512 sval = _mm512_permutexvar_ps(_fidx.i, r);
    s.m = _mm512_cmp_ps_mask(_fval.v, sval, _CMP_LT_OS) << 1;
    uint8_t _offset = Common::lookup[s.mm[0]];
    uint8_t offset = data[_fidx.ii[_offset + 7]] < _fval.vv[_offset + 7] ? _offset * 2 : _offset * 2 + 1;
    return _children[offset];
}
```
