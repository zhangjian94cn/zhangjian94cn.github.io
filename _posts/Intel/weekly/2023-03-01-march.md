### Selective Permutation

```cpp
inline uint8_t next(const __m512& r, const float* data) {
    nodeStat s;
    __m512 sval = _mm512_permutexvar_ps(_fidx.i, r);
    // __m256 sval = _mm256_permutexvar_ps(_fidx.i, r)
    s.m = _mm512_cmp_ps_mask(_fval.v, sval, _CMP_LT_OS) << 1;
    // uint8_t _offset = 0;
    uint8_t _offset = Common::lookup[s.mm[0]];
    uint8_t offset = data[_fidx.ii[_offset + 7]] < _fval.vv[_offset + 7] ? _offset * 2 : _offset * 2 + 1;
    return _children[offset];
}
```

直接使用`_mm512_permutexvar_ps`时，当`_fidx.i`出现超过15的数值时，core dump，核心原因在于：我们希望gather过来的node尽可能多，那么最大就是mm512，而为了提升共享率，实际compare时，只能使用前三层，第四层结点的feature index往往>15，从而导致问题

最简单的，增加`__m256i i2[2]`，再`_mm256_permutexvar_ps`，然而此种方式需要unpack `_fidx`，并不可取

```cpp
union FeatIdxType {
    __m512i i;
    __m256i i2[2];
    int32_t ii[gnodeNum];
};
```

查阅发现，可以使用：`_mm512_maskz_permutexvar_ps`指令，其与原始permute性能相同，完美符合我们的需求，实际验证，也不存较大性能损失

```cpp
inline uint8_t next(const __m512& r, const float* data) {
    nodeStat s;
    const __mmask16 mask = 0b1111111;
    __m512 sval = _mm512_maskz_permutexvar_ps(mask, _fidx.i, r);
    s.m = _mm512_cmp_ps_mask(_fval.v, sval, _CMP_LT_OS) << 1;
    uint8_t _offset = Common::lookup[s.mm[0]];
    uint8_t offset = data[_fidx.ii[_offset + 7]] < _fval.vv[_offset + 7] ? _offset * 2 : _offset * 2 + 1;
    return _children[offset];
}
```

### solve 2d parallel competition

1. 出现一个非常重要的问题：**多次运行出现的结果不一致**：
    > c++侧，由于2D parallel存在同时写入一块内存，存在竞争问题，导致数据结果不一致

2. 极少部分数据预测结果与xgboost不一致
    > 推测：当输入数据与节点值相等时，分支走向与xgboost不一致（解决 with yuliang）


前一版本代码实现如下，其中`res`在tree的维度上，是存在同时被多棵树写入的风险的

```cpp
static tbb::affinity_partitioner ap;
tbb::parallel_for(
    tbb::blocked_range2d<size_t>(0, nT, 0, nD), 
    [&](const tbb::blocked_range2d<size_t>& r){

    for(size_t i = r.cols().begin(); i != r.cols().end(); i++)
    for(size_t j = r.rows().begin(); j != r.rows().end(); j++)
    {   
        //printf("i is %d \n", i);
        //printf("j is %d \n", j);
        const int offsetD = i * iblockD, offsetT = j * iblockT;
        for (int kT = 0 ;kT < iblockT; ++ kT) {
            for (int kD = 0 ;kD < iblockD; ++ kD) {
                res[offsetD + kD] += \
                    gbt._trees[offsetT + kT].predictTree(data + (offsetD + kD) * featDim);
            }
        }
    }
}, ap);

tbb::parallel_for(0, nD, 1, [&](int i) {
    const int offset = i * iblockD;
    for (int j = 0 ;j < iblockD; j++) {
        res[offset + j] = sigmoid(res[offset + j]);
    }
});
```

解决方案是：针对每一个block设置一个独立的数据位，数组大小为：
```
nT = treeDim / iblockT
tmp_arr.size = dataDim * nT
```

具体实现如下：

```cpp
// exp 9 2D blocked parallel (tree outer, data inner) and use memory affinity
static tbb::affinity_partitioner ap;
tbb::parallel_for(
    tbb::blocked_range2d<size_t>(0, nT, 0, nD), 
    [&](const tbb::blocked_range2d<size_t>& r){
    
    for(size_t i = r.cols().begin(); i != r.cols().end(); i++)
    {
        for(size_t j = r.rows().begin(); j != r.rows().end(); j++)
        {
            const int offsetD = i * iblockD, offsetT = j * iblockT;
            for (int kD = 0 ;kD < iblockD; ++ kD) {
                float dt = 0;
                for (int kT = 0 ;kT < iblockT; ++ kT) {
                    dt += \
                        gbt._trees[offsetT + kT].predictTree(data + (offsetD + kD) * featDim);
                }
                tmp[(offsetD + kD) * nT + j] = dt;
            }
        }
    }
// });
}, ap);


tbb::parallel_for(0, nD, 1, [&](int i) {
    const int offsetD = i * iblockD;
    for (int j = 0 ;j < iblockD; j++) {
        float dt = 0.f;
        for (int k = 0; k < nT; ++ k) {
            dt += tmp[(offsetD + j) * nT + k];
        }
        res[offsetD + j] = sigmoid(dt);
    }
});
```
