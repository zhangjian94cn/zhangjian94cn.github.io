### Selective Permutation

```cpp
inline uint8_t next(const __m512& r, const float* data) {
    nodeStat s;
    __m512 sval = _mm512_permutexvar_ps(_fidx.i, r);
    // __m256 sval = _mm256_permutexvar_ps(_fidx.i, r)
    s.m = _mm512_cmp_ps_mask(_fval.v, sval, _CMP_LT_OS) << 1;
    // uint8_t _offset = 0;
    uint8_t _offset = Common::lookup[s.mm[0]];
    uint8_t offset = data[_fidx.ii[_offset + 7]] < _fval.vv[_offset + 7] ? _offset * 2 : _offset * 2 + 1;
    return _children[offset];
}
```

直接使用`_mm512_permutexvar_ps`时，当`_fidx.i`出现超过15的数值时，core dump，核心原因在于：我们希望gather过来的node尽可能多，那么最大就是mm512，而为了提升共享率，实际compare时，只能使用前三层，第四层结点的feature index往往>15，从而导致问题

最简单的，增加`__m256i i2[2]`，再`_mm256_permutexvar_ps`，然而此种方式需要unpack `_fidx`，并不可取

```cpp
union FeatIdxType {
    __m512i i;
    __m256i i2[2];
    int32_t ii[gnodeNum];
};
```

查阅发现，可以使用：`_mm512_maskz_permutexvar_ps`指令，其与原始permute性能相同，完美符合我们的需求，实际验证，也不存较大性能损失

```cpp
inline uint8_t next(const __m512& r, const float* data) {
    nodeStat s;
    const __mmask16 mask = 0b1111111;
    __m512 sval = _mm512_maskz_permutexvar_ps(mask, _fidx.i, r);
    s.m = _mm512_cmp_ps_mask(_fval.v, sval, _CMP_LT_OS) << 1;
    uint8_t _offset = Common::lookup[s.mm[0]];
    uint8_t offset = data[_fidx.ii[_offset + 7]] < _fval.vv[_offset + 7] ? _offset * 2 : _offset * 2 + 1;
    return _children[offset];
}
```
