术语与概念对照

本页目录交付与协作系统与网络容器与制品发布、数据与恢复观测与工程治理基础设施与集群可靠性、安全与扩展工作负载

术语用于准确讨论问题。先记住它解决什么、与相邻概念有什么区别，再记住缩写。本页的定义按本教程语境组织，不把某个具体产品等同于整个概念。

交付与协作#

术语 中文理解 容易混淆的边界
DevOps 围绕软件交付与运行建立共同责任和反馈 不是一个人的职位清单，也不只是一组工具
CALMS 文化、自动化、精益、度量、分享的观察维度 自动化只是其中一部分
Value stream 从需求到用户价值的活动与等待 不应只测开发者写代码的时间
Lead time 从定义的起点到终点的经过时间 必须说明起止事件与统计范围
Small batch 把变更拆成可独立检查的小批次 小 Commit 不一定形成可发布的小变更
CI 频繁集成并自动检查变更 配置了 CI 文件不等于检查真正有效
Continuous delivery 保持软件处于可按需发布状态 仍可在生产发布前设置人工决策
Continuous deployment 满足条件的变更自动进入生产 与手动点击发布不是同一流程
Pull request 把变更、讨论与自动检查放在同一审阅入口 审阅通过仍需处理目标环境发布条件
Definition of Done 团队约定的完成条件 “我写完了”不等于功能已完成
ADR 记录重要架构决定与理由 应记录取舍和后果，不只写结论
DORA 软件交付与组织实践的研究及度量框架 指标用于改进系统，不能简单排名个人

系统与网络#

术语 中文理解 容易混淆的边界
Process 正在执行的程序实例 一个服务可包含多个进程
PID 进程标识 在不同 PID namespace 中可能不同
Signal 向进程发送事件或控制通知 SIGTERM 允许处理，强制终止不能依赖清理逻辑
File descriptor 进程访问文件、socket 等资源的句柄 连接问题也可能来自句柄耗尽
Permission 某个身份对资源的操作许可 连接成功不代表有业务操作权限
DNS 把名称解析为地址等记录的系统 解析成功不代表端口可达
TCP 提供可靠有序字节流的传输协议 连接成功不代表 HTTP 业务成功
TLS 保护传输并提供证书身份验证机制 禁用证书验证会破坏关键保护
Reverse proxy 代表后端接收请求并转发的服务 代理正常不代表后端正常
Timeout 对一次等待设置边界 超时不一定意味着服务端没有完成写入
Retry 对失败或不确定操作再次尝试 非幂等写入重试可能产生重复数据
Idempotency 重复执行具有相同预期效果 不等于每次响应字节都完全相同

容器与制品#

术语 中文理解 容易混淆的边界
Image 可分发的文件系统层和运行配置 镜像本身不是正在运行的进程
Container 根据镜像启动的隔离进程环境 删除容器不等于删除独立卷
Namespace 为进程提供部分独立系统视图 隔离某个视图不等于完整安全边界
cgroup 对进程组进行资源统计与控制 不设置限制时不会自动获得合适的限额
Build context 构建时允许读取的文件范围 上下文中的秘密可能被意外带入构建
Layer 镜像文件系统变化的组成部分 后续层删除文件不抹掉此前层内容
Registry 存储与分发镜像等制品的服务 仓库登录权限与运行环境权限不同
Tag 指向某个制品的可读引用 标签可被重新指向，除非策略另有限制
Digest 基于内容的对象标识 要区分 index、manifest 和本地 image ID
Artifact 需要保存或传递的构建输出 与可随时丢失的加速缓存不同
Promotion 让已验证制品进入下一环境 环境间重新构建会产生新的待验证候选
Volume 独立于容器生命周期的存储挂载 持久卷不是备份

发布、数据与恢复#

术语 中文理解 容易混淆的边界
Deployment 把选定制品与配置带入目标环境 部署命令成功不等于业务验收通过
Release 把能力交付给目标用户的决定与过程 可与技术部署分离，例如通过功能开关
Smoke test 快速验证关键路径的检查 范围有限，不能替代全部测试
Liveness 进程是否能继续提供基本响应 不应把所有依赖失败都等同于进程死亡
Readiness 实例是否满足接收当前流量的条件 就绪通过也可能遗漏具体业务错误
Schema migration 数据结构或相关状态的有序变化 应用回退不会自动逆转数据变化
Expand/contract 先扩展兼容，再迁移使用，最后收缩 删除旧结构往往改变回退边界
Transaction 将一组操作按数据库规则作为整体处理 不能自动覆盖数据库之外的全部副作用
Rollback 把某个变更对象退回可用状态 必须说清是应用、配置还是数据库
Backup 为恢复保存的数据副本或恢复材料 备份文件存在不等于可以恢复
RPO 业务可以接受的数据损失范围目标 不一定等于备份任务的调度间隔
RTO 从约定起点到恢复条件的时间目标 没演练过就不能只凭配置宣称达标

观测与工程治理#

术语 中文理解 对应边界与展开
Log 某个事件的记录 结构化字段、上下文、脱敏与保留
Metric 对某类状态或事件的数值测量 标签基数、聚合、直方图和告警
Trace 一次请求跨组件执行的关联信息 传播上下文、采样与诊断
SLI 描述用户体验或服务行为的测量指标 选择有效事件与统计窗口
SLO 对 SLI 设定的服务目标 错误预算与工程决策
SRE 用工程方法管理可靠性的实践 事件响应、容量、自动化与减少重复劳动
IaC 以可审阅代码管理基础设施期望状态 状态文件、计划、漂移与销毁
GitOps 以声明式、版本化期望状态驱动持续协调 同步、漂移、晋级与访问边界
SBOM 软件组成材料清单 组件身份、漏洞关联与制品对应
Provenance 记录制品如何产生的来源信息 与构建身份、输入及验证关联
Platform engineering 为团队提供可使用、可维护的内部能力 用户需求、自助路径和平台运营
FinOps 围绕云使用价值与成本建立共同责任 成本归属、预算、使用优化和权衡

基础设施与集群#

术语 中文理解 容易混淆的边界
State IaC 记录管理对象关联与属性的状态 不是随时可删的缓存，可能含敏感数据
Drift 实际资源与所记录/声明状态之间的偏离 修复前先判断变化是否有意发生
Provider 将资源声明映射到目标 API 的组件 不同平台相似资源的语义未必相同
Reconciliation 控制器持续让实际状态接近期望状态 不是只执行一次脚本
Pod Kubernetes 调度的基本工作负载单元 常有多个协同容器，不等同于 VM
Deployment 管理无状态 Pod 副本与滚动变化的对象 不是所有部署行为的总称
StatefulSet 为有状态工作负载提供稳定身份等机制 不会自动让单实例数据库高可用
Service / EndpointSlice 稳定服务抽象与后端端点描述 资源存在不代表选到了就绪后端
Gateway / HTTPRoute 入口监听与 HTTP 路由的声明 需要对应控制器和数据面
CNI / CSI 容器网络与存储接入接口/实现生态 是否支持具体策略和卷能力由实现决定
PV / PVC 存储资源与使用存储的声明 卷持久性不替代独立备份
Request / Limit 调度资源需求与运行资源约束 语义和 CPU/内存超限结果不同
HPA 根据指标调整工作负载副本数 依赖指标、资源设置及可用容量
PDB 对适用的自愿驱逐限制不可用副本 不阻止所有节点故障或应用故障
RBAC 按角色授权 Kubernetes API 操作 不等于应用用户权限或网络隔离
PSA Pod 安全准入机制 不是漏洞扫描或完整多租户隔离
NetworkPolicy 声明适用 Pod 的允许网络路径 需要真正执行策略的网络实现
Helm / Kustomize 模板参数化与声明式配置组合 渲染结果仍要做实际环境验证

可靠性、安全与扩展工作负载#

术语 中文理解 容易混淆的边界
RED / USE 请求速率、错误、时长；利用率、饱和、错误 观察方法不同，不用单张图推断所有原因
Histogram 用区间记录观测值分布 分位数通常是估算，受桶边界影响
Cardinality 标签组合形成的不同时间序列数量 工单 ID 等无界标签会迅速放大成本
Error budget 目标窗口允许的坏事件量 不是可以任意消耗的停机许可
Burn rate 相对允许速率的预算消耗速度 必须说明观察窗口与分母
PITR 利用适当备份及连续日志恢复到时间点 普通 dump 不提供任意时间点恢复
OIDC 身份层与身份声明协议 短期令牌仍需要限定信任条件和权限
Admission API 写入接受前的准入处理 离线 lint 不替代真实入口约束
mTLS 双方验证证书身份的 TLS 加密与身份确认不自动提供业务授权
Outbox 与业务数据同事务写入待发事件 消费者仍需处理可能重复投递
Dead letter 无法正常处理消息的受控失败去向 需要责任、排查和重放，不能无限堆积
Evaluation gate 按明确样例与规则决定候选是否晋级 小型教学样例不能证明真实模型整体质量
Prompt injection 不可信内容试图影响模型遵循的任务或权限 不能只靠一句提示词替代工具权限控制

遇到缩写时，用一句话回答“它观察或控制什么”，再回到具体实验。关于工具当前版本和生命周期，以版本与验证以及章节链接的官方资料为准。
