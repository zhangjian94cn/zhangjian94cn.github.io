完整学习路线

本页目录五个阶段与验收关口三条建议阅读路径如何使用下面的目录

48 章主线分为 12 篇，另有 8 个按需阅读的场景专题。所有编号现在都有正文。先建立一条可运行的交付路径，再增加环境与运行复杂度；不要求读者一次安装全部工具。

五个阶段与验收关口#

阶段 章节 本阶段成果 本版执行边界
一：基础交付 01—20 需求、测试、CI、容器、发布、配置/应用恢复与备份校验 API 测试通过；容器、数据库、托管 CI 待运行
二：云与集群 21—32 云设计、IaC、Ansible、Kubernetes、Helm、GitOps 与流量切换 YAML、Helm 和 Kustomize 离线检查通过；真实平台待运行
三：运行与可靠性 33—40 指标日志追踪、告警、SLO、容量、恢复与复盘 指标 API 测试通过；真实采集、通知、压测与灾难演练待运行
四：安全与组织 41—48 身份、扫描、证明、策略、团队指标、平台、成本与毕业项目 离线门禁和脚手架检查通过；真实签名、准入和团队流程待验证
五：场景选修 49—56 平台迁移及传统、异步、AI 工作负载案例 幂等事务与本地规则评测通过；外部平台与真实模型待验证

正文中的验收条件是读者要证明的结果。作者没有运行过的环境不标记成功，详见验证记录。

三条建议阅读路径#

应用交付路径：01—04 → 09—20 → 33—40 → 41—48。遇到主机和网络问题回读 05—08；需要集群再读 21—32。

基础设施与运维路径：01—04 → 05—20 → 21—40 → 41—48。特别保留业务验证，避免只完成资源创建而不知道用户能否使用。

负责人路径：01、04、21、37、39、40、41、45—48，再按评审中的证据缺口回到具体实验。选修按已有环境和业务需求进入，不作为完成主线的硬性条件。

如何使用下面的目录#

每篇列出四章，点击标题阅读正文。专题展开后可查看范围、目标并进入文章。使用顶部搜索可按错误现象、命令、对象名或概念查找；答案页按相同编号组织。

后续完善重点是干净环境复现、版本快照、真实部署证据与读者试读反馈。反馈请提供章节、小节、工具版本、执行目录、预期、实际结果和脱敏日志；概念修正附官方依据。
