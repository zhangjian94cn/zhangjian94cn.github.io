AI/Agent 应用的交付与运行

学习目标为工单加入受控 AI 分类功能，将评测门禁与普通 CI/CD 连接，并能回退应用及配置组合
本页目录前置与实验范围把发布组合固定下来执行离线门禁接入真实模型时增加什么Agent 工具权限与副作用线上观察、灰度与回退验收、取舍与练习

把工单自动分到“账单、账户、其他”时，应用版本没有变化，Prompt 或模型变化也可能改变业务结果。AI 应用的发布单位应包含程序、模型选择、Prompt、工具权限、知识来源和评测基线。本专题使用确定性的本地规则桩演示发布评测机制，再说明接入真实模型需要补哪些验证。

前置与实验范围#

先完成 制品、灰度、SLO 和 AI 辅助。代码在 extensions/ai_demo.py，样例集在 extensions/ai_cases.jsonl，发布组合在 extensions/ai_bundle.json。无需网络、API key 或商业账户。

本地桩按关键词分类，不是大模型。它用于证明输入校验、评测失败阻止晋级、版本绑定和回退机制，不能证明真实模型准确率、抗提示注入能力或调用费用。本版也没有把分类结果自动写入主线 API。

把发布组合固定下来#

对象 为什么需要版本
应用与适配器 输入、输出校验、超时、错误处理会变化
模型与参数 同一 Prompt 在不同模型下结果可能不同
Prompt 与输出 schema 决定任务与机器可接受的结果
工具集合与权限 决定代理可以做什么，影响故障后果
知识库快照 检索内容变化会改变回答依据
评测集与判定规则 决定发布证据在什么样本上成立

本例 bundle 写明桩版本、Prompt 占位版本、数据集 SHA-256、允许标签和最低样例准确率。真实项目还应关联镜像 digest、模型提供方的明确版本信息及权限配置；若平台只提供可变别名，应记录这个可重复性限制。

执行离线门禁#

在 TicketDesk 项目目录执行：

python3 -m extensions.ai_demo \
  --bundle extensions/ai_bundle.json \
  --cases extensions/ai_cases.jsonl

评测器先校验样例文件摘要与 bundle 一致，再运行本地桩，统计正确数、总数和错误案例 ID。全部输出只能属于允许标签；样例为空、摘要不符、输入字段无效或准确率低于阈值都失败。输出中的耗时是本地规则计算时间，没有调用 token 成本。

要演练质量门禁，在临时目录复制评测集，把一个预期结果改成不同的合法标签，再更新临时 bundle 的数据集摘要；默认阈值 1.0 时应因质量下降失败。若不更新摘要，则应更早因制品组合不一致失败。两种失败验证的是不同控制。

接入真实模型时增加什么#

模型适配器应只接受必要字段，对正文长度、超时、重试和输出 schema 设置边界。模型返回的“分类”只能从允许集合选择；附带解释、代码或未知字段不应直接成为数据库命令。不可用时可回到人工队列或已验证规则路径，并显式标记降级。

使用人工审核过的保留评测集，覆盖类别边界、空文本、多语言、长文本、隐私内容与指令注入。训练或提示调优所用案例不能同时充当全部独立测试证据。质量阈值按业务损失确定；不要把这八个教学样例的 100% 当成生产目标证明。

Agent 工具权限与副作用#

分类任务通常不需要 shell、发信或生产部署能力。若后续增加“自动创建修复任务”等工具，应在服务端校验调用者、参数、目标对象与幂等键，限制次数和预算；模型说“用户已经批准”不能代替真实授权记录。

检索文档和工单正文都可能包含不可信指令。把内容作为数据输入，保留来源；工具权限由外部程序决定。每个有副作用的操作都要有审计记录和失败恢复方式，避免模型重试时重复发送通知或扣费。

线上观察、灰度与回退#

同时观察分类质量反馈、拒绝/降级率、调用错误、端到端延迟、单位请求成本与预算消耗。真实模型的质量反馈通常有延迟，不能只看 HTTP 200。采样保存最小必要上下文，保护工单中的个人和业务信息。

先对合成与影子流量评测，再向小范围真实用户开放；明确影子路径不能产生业务副作用。若错误类别明显增加，应回退整个发布组合，包括 Prompt、模型配置和知识版本，而不是只回退应用镜像。记录切换点才能解释观测差异。

验收、取舍与练习#

独立验收包括正例通过、质量负例失败、摘要篡改失败、无效标签失败，以及回到旧 bundle 后可重跑相同离线结果。真实模型上线还需提供独立评测、调用权限、费用、灰度与回退证据；这些不在本地桩已验证范围内。

练习：模型返回合法 JSON，但总把“退款”判成账户问题，为什么 schema 校验发现不了？如何设计数据与门禁？见 答案。继续参考 NIST AI 风险管理框架，把质量与风险要求落实为具体案例和运行控制。
