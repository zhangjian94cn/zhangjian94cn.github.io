# AI Agent 实践课：课程规划与实现 Spec

版本：v1.0。内容核查日期：2026-09-21。发布形态：个人网站静态教程、单文件离线阅读版、Markdown 正文、Python 实验与教学模板。

## 1. 目标与定位

以“从理解原理到交付一次可验收任务”为主线，覆盖智能体概念与结构、多智能体结构、演化与能力、构建工作流程、案例分享。新颖性来自可操作的前沿工程方法与失败演练，不依赖未经验证的模型排名或万能 Agent 叙事。

读者完成课程后，应能选择最小合适方案，画清模型与执行器的职责，写出 Agent Spec，运行离线实验，并用证据解释成功、失败和权限边界。

## 2. 读者用户故事

| 读者 | 用户故事 | 学习产出 |
|---|---|---|
| 初学者 | 我希望通过熟悉的工作情境理解 Agent，而不是先记缩写 | 方案选择卡、结构图、工具轨迹 |
| 产品经理 | 我希望判断什么任务值得做，并把交付与验收写具体 | 用户故事、Spec、样本与证据简报 |
| 研发 | 我希望看懂执行循环、状态与工具边界，并能复现失败 | Python 实验、工具契约、测试与适配计划 |
| 负责人 | 我希望看到任务价值、组织分工、成本、权限与人工决策 | 架构选择记录、决策包、评估口径 |
| 授课者 | 我希望在有限时间内讲清主线，让学员完成练习 | 90 分钟公开课和一天实训安排 |
| 网站维护者 | 我希望直接放到现有网站，也能单独更新章节 | 无运行时外部依赖的 HTML、Markdown 源码 |

## 3. 内容结构

| 用户要求 | 实现章节 | 最终能做什么 |
|---|---|---|
| 智能体的概念与核心结构 | 1–4：选型、部件、循环、Spec | 判断是否需要 Agent，说明各部件责任 |
| 多智能体系统的概念与结构 | 5–8：取舍、拓扑、协议、故障 | 解释何时拆分，如何协调与终止 |
| 演化、能力、构建与流程 | 9–12：演化、上下文/Harness、协议、实验 | 理解近期变化，运行最小受控骨架 |
| 智能体案例分享 | 13–16：产品调研、代码交付、省市平台、结课 | 把方法迁移到工作任务并提交作品 |

每课包含情境、概念解释、具体交付物、练习和参考答案。主案例为虚构工单 IT-2048：员工更换手机后无法完成多因素认证；政策 KB-MFA-03 为虚构教学政策。第一版只交付待审核草案，不执行账户变更。

## 4. 技术时效性

使用官方文档、官方工程文章和论文作为一手来源。区分发布日期、规范版本标识与核查日期。快变内容包括 MCP 2026-07-28、A2A 1.0 系列、Deep Agents v0.7 规划启用方式、Skills、Browser/Computer use、2026 年 Agent 评估实践。

基础概念不绑定具体模型 ID、收费、部署性能或统一行业成熟度。规范链接尽量固定版本，动态文档注明核查时间。公开案例与原创教学改编分开叙述。

## 5. 教学交互与素材

- 1 张 AI 生成的原创工作台插画，用于情境引入。
- 6 张原创 SVG 结构图：Agent 循环、多 Agent 协作、人工边界、上下文包、MCP/A2A、构建评估循环。
- 5 场景事件轨迹演示：正常、工具失败、恶意文本、预算耗尽、未授权工具。
- 并行耗时计算器：保留关键路径与串行开销，明确不能据此证明多 Agent 优越。
- 16 组可展开参考答案；打印时展开答案。
- 实验、Spec、评估数据、决策模板、讲师手册、术语表和模型适配指南。

## 6. 实验范围与边界

Python 3.10+ 标准库。默认 ScriptedPlanner 为规则模拟器，不是真实模型。政策检索是精确查找，不是语义 RAG。只有 read_ticket 与 retrieve_policy 是工具调用；草案生成、校验、结束是本地动作。模拟预算以循环次数计，不代表 Token 或费用。

五个场景验证控制循环与执行边界；12 个单元检查验证关键程序行为。真实模型接入、生成质量、网络超时、真实用量预算、抗提示注入性能、多 Agent 编排、生产权限与持久化恢复不在已运行验证范围内。适配指南清楚说明这些扩展点。

## 7. 网站交付约定

- `dist/` 是可直接发布的静态目录，共 18 个 HTML 页面：总览、16 课、资料页。
- 使用相对链接，允许放到个人网站任意子目录；无需域名硬编码。
- 正文在 HTML 中，搜索引擎与关闭 JavaScript 的读者仍可阅读。
- 不使用 CDN、外部字体、统计脚本、第三方运行时或在线模型调用。
- 单文件 `ai-agent-course.html` 内嵌正文、图像、样式与脚本，适合下载阅读；实验素材另在 ZIP 中。
- 所有页面采用中文标题、语义结构、可聚焦控件、移动端排版、跳到正文和打印样式。
- 不自动发布到用户个人网站；用户可以把 dist 内容复制到目标目录。

## 8. 验收标准

| 维度 | 验收 |
|---|---|
| 内容完整 | 四项要求映射到16课，每课有产出与练习答案 |

| 可复用 | 模板有明确字段，评估 JSONL 可解析且声明用途 |
| 网页 | 本地资源、下载与锚点有效，JavaScript 语法通过 |

| 交付 | ZIP 含源码和发布目录；单文件与Markdown可独立下载 |

## 9. 后续维护

建议按发布需要重新核查动态来源；更新协议或 SDK 内容时写明版本、日期与验证范围。课程案例可替换为已脱敏的真实组织任务，但必须重新定义政策、数据权限、验收与人工责任。

v1.0 不包含生产后端、身份认证、真实账户工具、在线大模型调用或未经运行的“完整框架接入代码”。后续是否增加，按读者的实际练习反馈决定。
