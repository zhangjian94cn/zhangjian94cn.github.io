# 术语速查

| 名称 | 中文与职责 | 别和什么混淆 |
|---|---|---|
| Agent | 在约束下根据观察选择行动的系统 | 不是所有聊天界面都具备自主循环 |
| LLM | Large Language Model，大语言模型 | 模型不是完整运行系统 |
| RAG | Retrieval-Augmented Generation，检索增强生成 | 是提供依据的方法，不等于 Agent |
| Workflow | 工作流，由预设结构组织步骤与分支 | 也可以包含模型节点 |
| Tool calling | 模型提出工具调用，程序负责验证与执行 | 生成了调用 JSON 不代表执行成功 |
| Observation | 动作返回的可观察结果 | 外部返回文本不是高优先级指令 |
| State | 当前任务的结构化状态 | 不等于完整对话记录 |
| Context | 本次模型调用看到的信息 | 数据库里有资料不代表模型已经看到 |
| Memory | 按规则跨步骤或任务保存的信息 | 向量库只是可能的实现之一 |
| Harness | 模型周围的运行、执行与观察框架 | 不是一种模型 |
| Checkpoint | 可恢复的状态检查点 | 不能自动消除外部副作用 |
| Idempotency | 幂等，同一逻辑操作重试不重复产生效果 | 幂等键需由服务端真正执行去重 |
| Handoff | 交接当前任务控制权与责任 | 与调用专家后等其返回不同 |
| MCP | Model Context Protocol，工具与上下文接入协议 | 不提供最终业务授权 |
| A2A | Agent2Agent，独立 Agent 服务互通协议 | 不是所有多 Agent 都需要它 |
| Skill | 可按需加载的任务说明与资源包 | 不是独立智能体或自动授权机制 |
| HITL | Human-in-the-loop，人在环中 | 人工意见、核验与审批仍需具体区分 |
| Trace | 运行轨迹，记录工具、状态、错误等事件 | 不要求暴露模型内部思维链 |
| Outcome | 任务结束时可检查的结果或环境状态 | 与模型文字声称成功不同 |
| Eval | Evaluation，评估 | 一次演示通过不是总体可靠性证据 |
| Grader | 评分器，可由代码、模型或人实现 | 模型评委不是最终事实来源 |
| Token | 模型处理文本等信息的单位 | 不等于字数；模拟循环预算不是 Token |
| P95 | 约95%观测值不超过的分位值 | 小样本与不同统计口径影响解释 |
| Spec | 明确用户故事、范围与验收的规格说明 | 不是开发完后补写的介绍 |
| MFA | Multi-Factor Authentication，多因素认证 | 课程政策是虚构示例，不是操作规程 |
| Prompt injection | 外部数据夹带试图改变模型行为的指令 | 不能仅靠一句提示词宣称已解决 |
