这门课怎么学？

每课按“场景 → 原理 → 产物 → 练习 → 答案”展开。先读核心课，再沿角色路线深入。自学主课约 8–10 小时，结课项目另留 3–5 小时；90 分钟公开课与一天实训安排见讲师手册。
