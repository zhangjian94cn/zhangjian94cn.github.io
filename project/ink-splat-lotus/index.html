01 · The Technology

不是把画面立起来，而是把颜色、体积与光重新写进空间。

3D 高斯泼溅（3D Gaussian Splatting）以三维高斯为基本单元。每一枚基元都携带位置、尺度、方向、颜色与透明度；数十万枚基元在 GPU 上被实时投影、排序与混合，最终连续成像，无需传统的三角网格与贴图。

它不是一张被弯折的图片，也不是一段预录视频。视角改变时，轮廓、遮挡与空间关系会被重新计算，于是这株莲花真正存在于浏览器里的三维场中，可以被环绕、靠近，也可以回应一次触碰。

本作从单幅水墨出发：BiRefNet 分离纸面与主体，TripoSplat 推断花、叶与茎的三维结构，Spark.js 再将 Gaussian Splat 交给 WebGL2 实时渲染。化墨与归形所使用的 GPU 粒子同样采自莲花本体，因此每一次流散都保留着原来组织的颜色与方向。

From Image to Field

一幅画，如何成为一方空间

  1. 01

    取形 / Reconstruct

    清理纸面背景，并从单幅观察中推断花、叶与茎的深度关系。

  2. 02

    成场 / Render

    用半透明高斯基元承载柔边与晕染，在 GPU 上实时完成投影、排序与混合。

  3. 03

    入境 / Interact

    让射线命中真实表面，让同源点云沿着流场化开，并在留白中重新聚拢。

02 · The Aesthetics

技术给它空间，水墨给它时间。

水墨最动人的地方，不只是已经落下的笔，更是墨色将尽未尽、纸面仍在呼吸的那一刻。Gaussian Splat 的柔边、半透明与离散结构，恰好允许形体停留在“有”与“无”之间。

因此，这里没有把莲花塑成坚硬的三维物件。花瓣仍保留胭脂的薄，荷叶仍有焦墨与淡墨的层次；当它化开，光先在轮廓上凝住，随后组织顺着同一股风散入宣纸，最终把画面还给安静的留白。

我想做的，不是把国画变成一个 3D 模型，而是让一笔墨从纸上的瞬间，延伸成一段可以被观看、触碰与等待的时间。
